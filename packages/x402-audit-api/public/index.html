Coverage

What gets audited

Every audit runs both static code analysis and live dynamic probing against the deployed endpoint.

code
Static Analysis
  • shield_lock
    CORS Misconfiguration
    Reflected-origin + credentials flags that allow any site to read 402-gated responses
  • lock_open
    Payment Bypass Patterns
    Presence-only checks (if headers['x-payment']) that skip verification entirely
  • key_off
    Hardcoded Secrets
    Private keys, mnemonics, and API keys committed in source code
radar
Dynamic Probing
  • vpn_key_off
    Live Auth Bypass
    Sends a fake X-Payment header to the live endpoint and checks if access is granted
  • public
    CORS Credentials Probe
    Checks if Access-Control-Allow-Credentials: true is returned with an arbitrary origin
  • error_outline
    Info-Leak Probe
    Checks if error responses expose stack traces, internal paths, or environment details
Integration

How it works

Three HTTP calls. No account required. x402-native flow.

1
GET /audit?repo=<github-url>
Receive an HTTP 402 response with payTo addresses for both Base and Solana, amount, and payment instructions.
2
Send $0.99 USDC
Pay from Base (EVM tx hash) or Solana (base58 signature). Chain is auto-detected — no extra configuration needed.
3
POST /audit with X-Payment header
Submit the tx hash. Receive a full audit report in ~30 seconds: severity-rated findings, fix guidance, and an overall PASS/REVIEW/FAIL verdict.
